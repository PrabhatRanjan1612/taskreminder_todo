Task Reminder Application

Project Documentation Developed using Django Framework
  1. Introduction

    The Task Reminder Application is a simple web-based app developed using Django that allows users to add tasks with due dates and receive reminders. The app is designed to help users stay organized by managing their daily tasks efficiently.

  2. Objective of the Project

    • - To provide a user-friendly platform to manage tasks

    • - To allow users to add and view tasks with deadlines

    • - To help users remember important tasks with reminders

    • - To practice CRUD operations and datetime handling in Django

  3. Software and Technology Used

    • - Backend: Python, Django Framework

    • - Frontend: HTML, CSS

    • - Database: SQLite (Django Default)

    • - Tools: VS Code,Browser (Chrome/Firefox)

  4. Modules Description
      - User Module:

    • Register/Login

    • Add/Edit/Delete Tasks

    • View Upcoming Tasks

    - Task Module:

    • Store task title, description, due date

    • Filter and display tasks based on date

  5. System Requirements

    • - Operating System: Windows/Linux

    • - Python 3.10+

    • - Django 4.x

    • - Web Browser

    • Code Editor (VS Code recommended)

  6. Database Schema
      -Task

    • ID

    • Title

    • Description

    • Due Date

    • Created Date

    • Completed (Boolean)

      -User

    • name

    • Username

    • Password

  7. Future Scope

    • - Add email or SMS reminders

    • - Add task priority levels

    • - Enable recurring tasks

    • - Calendar view for tasks

    • -Mobile responsive UI

  8. Conclusion

    • The Task Reminder App provides a useful tool for managing daily tasks and deadlines. It helps users boost productivity and stay organized. It is a scalable project suitable for beginners to practice Django with practical functionality.
